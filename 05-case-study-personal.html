A one-page personal site with a Hire Me popup

An earlier personal site from June 2025: one scrolling page that introduces me, rates six skills, lists three services and ends with a Hire Me form that opens in a popup. Built in Elementor on the OceanWP theme.

Self-initiated practice project — my own earlier site. Kept as I built it in June 2025. The footer's sample text is the theme's, not mine.

What it is

A personal site I built in June 2025, in my first year of BSIT, to learn Elementor. It is a single page: who I am, what I was learning, what I could do, and a way to hire me. The About text is from that time, so it still describes a first-year student.

What I built

  • One page in five sections. The menu items are anchor links, so About, Service and Contact scroll down the page instead of opening new ones.
  • A skills section with six progress bars: WordPress, web design, Canva, video editing, MS Office and troubleshooting.
  • A Hire Me popup. Popup Maker opens it from any Hire Me button on the page, and a Contact Form 7 form inside asks for a name, email, business name and the service needed.
  • Separate desktop and phone layouts for the About section, using Elementor's per-device visibility settings.
  • Built up over 84 saved versions of the page between 3 and 20 June 2025, one section at a time. The headline changed from "WordPress Developer" to "Website Developer" along the way.

What the live copy cannot do

The live version is a static copy, because GitHub Pages cannot run PHP. The page, the menu and the popup all work. The Hire Me form sends through Web3Forms instead of Contact Form 7, which emails each message on to me. Site search needs WordPress, so the live copy says so when you try it.

What I would do differently

The About section exists twice, one copy for desktop and one for phones, so every change to the text has to be made in two places. One section with per-device layout settings would have done the same job. The footer also still carries the theme's sample content: a lorem ipsum "About Evan" block and a Facebook link to Apple's page, and the social icons point at Facebook's home page instead of a profile. I would clear every piece of demo content before calling a site finished.
