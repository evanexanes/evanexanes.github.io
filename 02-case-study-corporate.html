A four-page company site, built in Elementor

Home, About, Services and Contact for a company that does not exist, built from Elementor's standard widgets on the OceanWP theme.

View live site View on GitHub

Self-initiated practice project — placeholder content. Names, text and images in this build are dummy content, not a real client's.

Role
Solo build
Build size
4 pages
Stack
WordPress · Elementor · OceanWP

What it is

A small company website with the four pages most company sites start with. The names and text are placeholders; there is no real company behind it. The point was the build, not the business.

What I built

  • Four pages in Elementor. Home has counters and a testimonial, About uses two accordions, Services is a run of headed text blocks, and Contact pairs an icon list of contact details with a form.
  • OceanWP as the base theme. The theme handles the header, menu and footer; Elementor handles everything inside the page.
  • A working contact form with Contact Form 7, dropped into the Contact page by shortcode.

What the live copy cannot do

The live version is a static copy of the WordPress site, because GitHub Pages cannot run PHP. The pages look and link the same. Contact Form 7 needs PHP too, so on the live copy the form sends through Web3Forms instead, a form service that emails each message on to me.

What I would do differently

Every page is built on its own. Nothing is saved as a reusable Elementor template, so a fifth page would start from a blank canvas. My store build uses Elementor's theme builder for exactly that, with one template per page type, and this site would have benefited from the same approach.
